Naive search compares the pattern at every shift, up to O(nm). KMP uses the failure function (LPS array) to skip redundant comparisons, guaranteeing O(n+m). Rabin-Karp hashes each window and only does character comparisons when hashes collide, averaging O(n+m) but degrading on frequent hash collisions.
